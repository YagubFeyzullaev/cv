# FinanceTracker (iOS, SwiftUI)

Минималистичное приложение для учета личных финансов: ежедневные расходы и доходы, сбережения и вклады, категории трат и наглядная аналитика на графиках.

## Возможности
- Добавление расходов и доходов с выбором категории, счета и даты
- Счета: наличные, карта, сбережения, вклад
- Ежедневная лента транзакций, фильтры (все/расходы/доходы)
- Дашборд: баланс, траты по дням за текущий месяц, Топ категорий
- Аналитика: круговая диаграмма трат по категориям, бары по месяцам
- Минималистичный, чистый UI на SwiftUI
- Хранение данных локально (SwiftData, iOS 17+)
- Графики на Charts (iOS 16+)

## Требования
- Xcode 15+
- iOS 17+ (SwiftData)

## Как запустить (быстрый способ)
1. Откройте Xcode → File → New → Project… → App
2. Product Name: FinanceTracker, Interface: SwiftUI, Language: Swift. Убедитесь, что платформа iOS, Deployment Target ≥ 17.0
3. Созданный проект откройте в Xcode. В проект добавьте все файлы из папки `FinanceTracker` этой рабочей области (перетащите папку в навигатор Xcode с “Copy items if needed”).
4. Замените сгенерированные по умолчанию `App` и `ContentView` на версии из этой папки.
5. Соберите и запустите на симуляторе или устройстве.

## Структура исходников
- `FinanceTrackerApp.swift` — точка входа, конфигурирование SwiftData
- `Models/` — модели SwiftData (`Transaction`, `Account`) и типы (`TransactionType`, `AccountType`, `Category`)
- `Views/` — экраны: `DashboardView`, `TransactionsListView`, `AddTransactionView`, `AccountsView`, `AnalyticsView`, `ContentView`
- `Utils/` — форматтеры, помощники по датам, первичное наполнение (`Seeder`)

## Данные по умолчанию
При первом запуске создаются счета (Наличные, Карта, Сбережения) и несколько примерных транзакций для демонстрации графиков.

## Скриншоты (описание)
- Главная: общий баланс, линейный график трат по дням, топ категорий
- Транзакции: список, фильтр по типу, добавление новой записи
- Аналитика: круговая диаграмма категорий за месяц и бары по месяцам
- Счета: список счетов с балансами и добавление нового счета

## Примечания
- Категории трат: кафе и рестораны, бензин, продукты, транспорт, дом, развлечения, здоровье, одежда, подписки, путешествия, прочее
- Категории доходов: зарплата, подарки, проценты, фриланс
- Баланс каждого счета = стартовый баланс + сумма доходов − сумма расходов для этого счета
